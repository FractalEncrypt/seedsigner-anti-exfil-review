# Save test feedback

The Windows kit includes three local, editable forms:

- **FEEDBACK-OFFLINE.html** for prepared offline signing.
- **FEEDBACK-LIVE.html** for live signing, broadcast and optional confirmation.
- **FEEDBACK.html** for the full set, including additional checks.

Open the form matching your path. Record only the checks you tried and leave
others Not run. Every result has a Steps link. Click **Save feedback HTML** and
keep the downloaded copy; reopen it to keep editing. Save screenshots separately.
The page does not submit your data. Its optional issue-draft button prepares
text you can review and submit yourself. Include the TXID and network only if
you want to share a live test result.
