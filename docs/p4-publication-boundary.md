# P4 publication boundary

The v2 source branch, deterministic archive, manifest, and P5 prompt are local
review candidates. P4 authorizes and performs no tag, push, release, GitHub issue
comment, upstream pull request, firmware publication, or public distribution.

P5 is the independent review gate. Acceptance there may establish that the
candidate is eligible for a separately owner-authorized publication operation;
it does not itself publish anything.

Any later publication authorization must name the exact review-hub commit/tree,
archive filename/bytes/SHA-256, Drongo/Sparrow/Kern candidate commits, proposed
tags/branches, release assets, repositories to push, and any issue update. A
change after accepted review invalidates the reviewed archive and requires a
new manifest/hash and review disposition proportional to the change.
