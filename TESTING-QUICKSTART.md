# Try anti-exfil signing

Start with [Download and test](docs/download-and-test.md). The Windows x64 kit
includes Sparrow, device images, public fixtures and saveable HTML feedback.
Choose [offline signing](docs/offline-public-fixture-testing.md) or
[live testnet signing](docs/end-to-end-testnet-testing.md). One successful
singlesig run is useful; multisig and further checks are optional.
Use the kit's offline or live feedback page, or its full form. Every result has
a Steps link. Click Save feedback HTML and reopen the downloaded copy to edit.
